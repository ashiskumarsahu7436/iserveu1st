# Assessment Notes

This repository is a starter template, not a final assessment solution. The real problem statement may change the entities, business rules, API shape, or frontend requirements.

## Suggested workflow

1. Read the final problem statement carefully.
2. Identify the entities and relationships.
3. Identify required APIs and validation rules.
4. Modify `database/schema.sql` and `database/seed.sql`.
5. Modify the Express routes and service logic.
6. Modify the React dashboard and forms if needed.
7. Run with Docker or Podman.
8. Test happy paths and failure cases.
9. Commit and push to GitHub if required.

Keep the code simple while working under time pressure. The route handlers intentionally show the important SQL and transaction boundaries rather than hiding them behind a large framework.
