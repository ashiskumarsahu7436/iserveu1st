# Requirements

iserveu1st is a deliberately small wallet system starter for timed technical assessments.

## Current scope

- Select or create a sample user.
- Create a wallet for a user.
- View the current wallet balance.
- Deposit money.
- Withdraw money when the balance is sufficient.
- Transfer money to another wallet.
- View transaction history and summary totals.
- Run the entire stack with local PostgreSQL in Docker or Podman.

This is an educational simulation. It does not authenticate users, connect to payment gateways, or process real money.
